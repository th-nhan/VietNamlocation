🌏 VNLocation - Travel Booking Website
📌 Introduction

VNLocation is a travel booking website that helps users easily explore destinations and schedule their trips across Vietnam.
The platform allows travelers to browse travel locations, view detailed information, and book tours conveniently.

This project is built using HTML, CSS, and JavaScript, focusing on creating a simple, responsive, and user-friendly interface.

🎯 Project Objectives

Provide travelers with an easy way to explore travel destinations.

Allow users to book tours or schedule trips online.

Practice front-end web development using pure HTML, CSS, and JavaScript.

Build a responsive and interactive travel website interface.

🚀 Features

🌍 Destination Listing
Display popular travel destinations across Vietnam.

📅 Tour Booking / Schedule System
Users can choose dates and book tours easily.

👤 Customer Information Form
Collect customer details for booking confirmation.

🖼 Image Gallery
Showcase attractive travel destinations.

📱 Responsive Design
Website works on desktop, tablet, and mobile devices.

⚡ Interactive UI with JavaScript
Dynamic elements such as form validation and booking interaction.

🛠 Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and responsive design

JavaScript (Vanilla JS) – Interactivity and dynamic behavior
